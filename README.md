# News API with Authentication

API для новостей с системой аутентификации и авторизации.

## Запуск

1. Установите зависимости: pip install -r requirements.txt
2. Настройте PostgreSQL базу данных
3. Запустите: uvicorn main:app --reload
4. Откройте http://localhost:8000/docs

См. [docs/auth.md](docs/auth.md) для описания ролевой модели.
